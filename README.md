# 栈闩工房

机关推箱子 + 回声校准的纯前端工房。不同种类的箱子触发对应踏板，踏板改变门、地板与竖起的封板，记录步数并保存已完成关卡的最佳成绩。

## 两种关卡

- **推箱关**：把箱子推上认得它的踏板，门与地板随之开合。
- **回声关**：门缝透出的声音经直达与一次反弹抵达听音位。给随踏板竖起的封板贴定长隔音条，使得指定的「踏板占用 × 听音位」组合在每个音高上都能靠左右耳响度差分清每一对门。贴条只吞掉打到本板的反弹，板照样立着挡声、挡路；各条路径按相位叠加，不能把音量直接相加。调好后走到听音位、蒙眼听回声报出门，才放行。

## 本地运行

```bash
npm install
npm run dev
```

类型检查、关卡自检与生产构建：

```bash
npm run typecheck
npm run verify     # 回归验证三关的封条预算、解法、可走通性与交货流程
npm run smoke      # 在 jsdom 里挂载应用并操作回声面板
npm run build
```

## Docker

```bash
docker compose up --build
```
